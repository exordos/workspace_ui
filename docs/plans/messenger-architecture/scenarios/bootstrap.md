# Bootstrap мессенджера

[Карта заметок](../README.md)

Начальная тема для разбора. Оболочка предоставляет контекст сессии и запускает мессенджер. Мессенджер координирует восстановление данных, обновление каталога и запуск своей фоновой работы.

```ts
const messengerSession = messenger.start(session);
// При завершении этой сессии.
messengerSession.stop();
```

В текущем коде запуск связан с [хуком оболочки](../../../../packages/web/src/widgets/layout/layout-workspace-messenger-bootstrap.hook.ts), который использует [операцию bootstrap каталога](../../../../packages/web/src/entities/messenger/messenger-bootstrap.lib.ts).

Для отдельного разбора:

- В какой момент готовы каталог, [история](load-messages.md) и курсор для [realtime](realtime.md).
- Какие процессы живут вместе с сессией и продолжаются при открытии почты или календаря. Сюда относится [доставка из очереди](send-message.md#5-подготовка-и-доставка).
- Как остановить работу при смене аккаунта или проекта и отклонить поздние записи. Общие правила описаны в [документации по асинхронным операциям](../../../ORG_SCOPED_ASYNC_SAFETY.md).
- Что нужно поддерживать для активной и фоновых сессий и где создавать экземпляры модулей.

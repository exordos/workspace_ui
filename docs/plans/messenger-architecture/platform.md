# Платформа Workspace

[Карта заметок](README.md) · [Дерево src](source-structure.md#дерево) · [Направление зависимостей](dependencies.md#направление-зависимостей)

В целевой структуре `packages/web/src/platform` предоставляет инфраструктуру для мессенджера, календаря, почты и общих модулей. Уже доступны [буфер обмена](#буфер-обмена-и-мост-electron), [системные уведомления](#системные-уведомления), [интеграция с ОС](#интеграция-с-ос) и [транспорт realtime](#транспорт-realtime).

| Часть           | Ответственность                                                                                       |
| --------------- | ----------------------------------------------------------------------------------------------------- |
| `auth`          | Вход, выход и работа с токенами                                                                       |
| `sessions`      | Список авторизованных сессий, контекст владельца, текущий выбор для UI и проверка актуальности сессии |
| `http`          | Запросы в контексте сессии, отмена и транспортные ошибки                                              |
| `realtime`      | WebSocket, догрузка событий по HTTP, курсор и переподключение                                         |
| `storage`       | Доступ к локальным хранилищам, включая IndexedDB, и изоляция данных по владельцам                     |
| `desktop`       | Доступ web к возможностям Electron через его существующий мост                                        |
| `notifications` | Показ системных уведомлений и передача кликов вызывающему коду                                        |

## Граница с app и мессенджером

`platform/sessions` предоставляет [контекст владельца и проверку актуальности запроса](../../../packages/web/src/platform/sessions/workspace-runtime.lib.ts) с типами из [workspace-runtime.types.ts](../../../packages/web/src/platform/sessions/workspace-runtime.types.ts). `entities/workspace-auth` владеет IAM-сессией, токеном и выбранным контекстом. [Сборка runtime](../../../packages/web/src/app/workspace-session/workspace-session.lib.ts) остаётся в `app/workspace-session`, а realtime transport — в `platform/realtime`.

- **`app`** создаёт runtime каждой авторизованной сессии, собирает приложения и общие модули, подключает их обработчики к транспорту. Оболочка привязывает UI к выбранному runtime. [Сборка сессии](workspace-runtime.md#сборка-и-доставка-событий)
- **`platform`** выполняет запрос, доставляет событие, предоставляет операции чтения и записи и показывает переданное ему уведомление. Транспорт получает обработчик при сборке.
- **Мессенджер** решает, что изменение сообщения означает для истории, списка чатов и исходящих. Он владеет схемой и правилами своего кеша, а его сценарий уведомлений определяет, когда вызвать показ.

Например, транспорт передаёт `message.created` обработчикам сессии. Мессенджер применяет сообщение, решает, обновить ли превью, и сохраняет нужные данные через `storage`. Если правила мессенджера разрешают уведомление, `notifications` показывает его через доступный системный механизм. [Обработка сообщения](scenarios/realtime.md#2-как-событие-доходит-до-сообщений)

## Кеш IndexedDB на первом этапе

На первом этапе сохраняем существующий кеш мессенджера в IndexedDB. Сохраняем его схему, ключи и форматы записей, уже накопленные данные и существующие методы чтения, записи и очистки с их текущим поведением. Новые модули продолжают читать данные, записанные до рефакторинга. [Текущий контракт кеша](../../WORKSPACE_MESSENGER_CACHE.md#invariants)

В этот этап входит изменение того, кто и когда вызывает эти методы. Например, runtime восстанавливает кеш своей сессии при запуске, а обработчик мессенджера применяет обновления через существующие операции записи, пока сессия работает в фоне. Изменения устройства кеша и его гарантий обсуждаем отдельно, если возникнет конкретная потребность.

## Буфер обмена и мост Electron

Приложения используют операции `writeText(text)`, `writeImage(image)` и `readText()` из [адаптера буфера обмена](../../../packages/web/src/platform/desktop/clipboard.ts). Запись принимает значение или промис и возвращает `Promise<boolean>`. Чтение возвращает `Promise<string | null>`.

```ts
import { writeText } from "~/platform/desktop/clipboard";

const copied = await writeText(messageLink);
```

```text
Код в web → platform/desktop/clipboard → window.electronAPI.clipboard.writeText
         → preload → IPC clipboard:writeText → Electron main → буфер обмена ОС
```

В браузере адаптер использует `navigator.clipboard`. Для асинхронно подготовленного текста запись через `ClipboardItem` начинается во время пользовательского действия. Браузерная ветка подготавливает PNG для записи изображения.

В Electron адаптер обращается к существующему `window.electronAPI.clipboard`. Пакет Electron публикует мост через `contextBridge`, выполняет чтение и запись в системном буфере и возвращает результат через IPC. [Методы preload](../../../packages/electron/src/preload.ts#L49) · [Обработчики IPC](../../../packages/electron/src/main.ts#L1076)

`Copyable` вызывает переданный `onCopy` при нажатии и отображает результат. Код профиля и медиапросмотр передают операции копирования текста и изображения. `deeplink.share(data, copyText)` использует переданную функцию, когда Web Share API недоступен. [Copyable](../../../packages/web/src/shared/ui/copyable/index.ts) · [Общий помощник ссылок](../../../packages/web/src/shared/lib/deeplinks.ts)

## Системные уведомления

`notificationService` управляет разрешениями, показывает и закрывает уведомления по тегу, передаёт клики вызывающему коду и обновляет счётчик на значке приложения там, где это поддерживается. Браузер и PWA используют Web Notifications API, Electron обращается к системному показу через существующий IPC. [Сервис уведомлений](../../../packages/web/src/platform/notifications/notifications.ts) · [Мост Electron](../../../packages/electron/src/preload.ts#L106)

Оболочка проверяет правила показа и собирает заголовок, текст, тег и маршрут. Она вызывает `notificationService.show(options)` и обрабатывает переход по клику. [Хук оболочки](../../../packages/web/src/widgets/layout/layout-workspace-notifications.hook.ts)

Точка входа приложения передаёт в API плагинов функцию `showDesktopNotification(title, body)`. Плагин вызывает `api.notify(title, body)`, когда его манифест объявляет разрешение `notifications`. [Подключение в приложении](../../../packages/web/src/main-app.tsx) · [API плагинов](../../../packages/web/src/shared/lib/plugins/api.ts)

## Интеграция с ОС

`osIntegration` управляет бейджем на значке приложения, индикатором прогресса, привлечением внимания к окну и настройкой автозапуска. В Electron адаптер обращается к `window.electronAPI.os` через IPC. В браузере бейдж выставляется и сбрасывается через App Badging API при его наличии. Для остальных операций веб-ветка возвращает значения по умолчанию или пропускает системный вызов. [Адаптер](../../../packages/web/src/platform/desktop/os-integration.ts) · [Мост Electron](../../../packages/electron/src/preload.ts#L130)

Оболочка вычисляет, нужен ли бейдж по непрочитанным личным сообщениям и упоминаниям, и решает, запрашивать ли внимание при показе уведомления. Она передаёт эти действия адаптеру через `setBadgeCount` и `requestAttention`. [Хук бейджа](../../../packages/web/src/widgets/layout/layout-app-icon-badge.hook.ts) · [Хук уведомлений](../../../packages/web/src/widgets/layout/layout-workspace-notifications.hook.ts)

## Транспорт realtime

`platform/realtime` открывает WebSocket, догружает события по HTTP, управляет переподключением и хранит курсор по владельцу сессии. Транспорт продвигает курсор после применения события и проверки актуальности попытки. [Транспорт](../../../packages/web/src/platform/realtime/workspace-realtime-runtime.lib.ts) · [Курсор](../../../packages/web/src/platform/realtime/workspace-realtime-cursor.lib.ts)

`app/workspace-session` собирает один runtime на каждого авторизованного владельца, выбирает для него активный или фоновый режим и передаёт транспорту параметры запросов, обновление токенов, подготовку снимков и обработчики событий. Обработчики обновляют данные в своих доменах. [Сборка](../../../packages/web/src/app/workspace-session/workspace-session.lib.ts) · [Контракт обработки и повтора](workspace-runtime.md#контракт-продвижения-курсора)

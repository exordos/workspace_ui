## Нужен ли один таймер автозакрытия опросов на открытый список сообщений?

Сейчас у каждой отрисованной карточки опроса с будущим сроком есть свой таймер. В загруженной истории остаются и карточки за пределами экрана. При смене темы карточки прежнего списка снимают таймеры и обработчики событий. Опросы, которые хранятся только в кэше других чатов, таймеров не создают. [Код карточки](../packages/web/src/widgets/workspace-message-list/workspace-poll-message-bubble.ui.tsx).

**Предложение для обсуждения.** Открытый список держит один таймер до ближайшего срока. Когда таймер срабатывает, список обновляет все карточки с истёкшим сроком и назначает таймер на следующий. При смене темы старый таймер снимается. Если автор перенёс или убрал срок либо пользователь вернулся в спящую вкладку, список заново определяет ближайший срок.

**Что проверить.** Измерить расход памяти и время обработки возврата во вкладку при разном числе загруженных опросов. Сто опросов — пример для замера. Порог, при котором пользователь заметит проблему, пока неизвестен.

These are navigation anchors in **Exordos Core (Copy)**. Use a node ID with Figma Bridge `get_node` or `get_screenshot` after resolving the connected file. Read the row for the interaction in scope. Inspect the actual layers and visible state before applying a pattern.

## Choosing a reference

A named state and its neighbors are stronger references than an isolated button. Some finished mobile frames have generic iPhone names. Their parent section and contents identify them.
- `ui-кит` (`12:18`) contains component sets, ordinary frames illustrating compositions, and drafts. Check the node type. The `modal windows` section (`13944:37361`), for example, contains `Checkbox` with an open-emoji variant and `Menu`. Find the actual dialog shell in a screen with the same interaction.
- `Юзабилити-тесты` (`12052:50`) includes findings, proposed fixes and a composed `Исправленный` frame (`14484:28192`). For multi-quote changes, check that each excerpt can be matched to its reply. For topic creation, check that the destination conversation is visible. Compare the revised frame before treating a research suggestion as an adopted convention.
- `Черновик (messenger)`, `Ченовики (делать не нужно)`, palette experiments and `Прототип` are useful history. Prefer a corresponding product state. The board `Workspace · Опросы` (`17416:31049`) is on `Запасной (пустой 3)` and explicitly contains alternatives and open decisions. For polls, trace composer entry → creation dialog → bubble before/after voting → author actions. Check the requested alternative before reusing it.

- `Сайт-визитка` (`828:1488`) contains separate product surfaces: the public site, Exordos account and marketplace, `Ui-kit for AI Dark` (`10649:6916`), Realms and Billing. Use these for work on the corresponding surface. For a messenger dialog, start on the messenger pages.

## Composition across screens

- **Keep the user's place.** On desktop the selected conversation stays visible while supplementary information occupies the right column. A message action menu sits by the invoking bubble; a creation dialog sits over a dimmed conversation. Compare the topic menu (`4281:13343`) with its creation dialog (`4283:17737`). Use the overlay size and position for the same kind of action.
- **Match the navigation level on mobile.** A conversation list can show search, folders and the bottom tab bar. An open thread gives that bottom edge to the composer. Multi-select replaces it with the count and actions (`13796:41753`). A recipient picker restores search and folders, and offers Cancel (`13796:41168`). Choose the surrounding navigation for the task at hand.
- **Show when an action becomes available.** The mobile login pair (`12052:42935` / `12052:43089`) turns the primary button from subdued to accented as the fields are filled. In the invalid state (`12052:43156`), the inputs carry error outlines and nearby explanations. Channel creation (`12152:28520`) pairs a quiet Cancel with an accented Create. Use the active theme's accent and reserve the destructive treatment for the destructive action.
- **Carry the same identity across views.** In the mobile channel list (`12052:41690`), the topic stripe, name, count and notification indicator identify distinct things. The forward-to-topic picker (`13796:42060`) reuses those cues. In the thread, incoming bubbles align with the sender's avatar, outgoing bubbles align to the opposite edge and use their own background and receipt. Keep these cues when changing the contents of a row or bubble.

## Foundations from the UI kit

- **Color and type.** `Palette new` (`11699:34650`) pairs tables and examples for Orange Warm, Blue Mist, Blue Cold and Emerald Chat. Match roles such as `msg-bg`, `msg-own-bg`, `msg-selected`, `sidebar-unread` and `text-muted` within one palette. Use `get_variable_defs` to inspect the real `Collections` and `Tokens` names, including spellings such as `Color/Massage/ownBackground`. Those palette examples are frames. Check the node for its actual variable or fill. `typography` (`40:27051`) shows Helvetica Neue weights. Read font, weight, size and line height from the text layer with the matching role.
- **Conversation list.** In `ui massanger` (`1477:5484`), `group chat/ channel` has closed, open and more-topics states. `Arrow-b icon` has open and no-topic states. Preserve the association between the parent row and its topic rows. `notification` distinguishes base, no notice and disabled. `room` distinguishes up to seven participants from larger groups. Choose the applicable avatar and notification variant from the same screen.
- **Messages.** Use `group message from one person`, the matching short/long bubble and the last/intermediate variant. The desktop spacing board (`1852:4543`) explicitly specifies **4 px** within a sender group, **8 px** between senders, and **16 px / divider / 16 px** between topics. These measurements apply to the conversation timeline. For outgoing status, check `read receipt` (Sent, Delivered, Read), plus the separate examples for pending and delivery error. Match ownership, grouping and status independently.
- **Attachments and quotes.** `files and attachments` (`13944:37363`) distinguishes `Sender's files` and `Files`, with file/image and loading/error variants. Compare before-send and sent frames to choose the family. Mobile photo groupings live in `photo layout (mobile)` (`13944:37362`). `citation / multicitata` (`13944:37360`) shows own/incoming layouts and contains the `citation/multicitata` component set.
